# חדר המצב — רפורמה תחת לחץ

אפליקציית סימולציה בעברית RTL: חמש משלחות, מנחה ומקרן. ארבעה משברים לאורך מפגש מתוכנן של 60 דקות, הסכם בשלוש דרגות התחייבות, עתיד מדומה, תיקון ורפלקציה.

## הרצה

נדרש Node.js 24 ומעלה (נעשה שימוש ב־`node:sqlite`).

```sh
npm ci
npm run dev
```

פתחו את הכתובת שהשרת מציג. בעמוד הבית אפשר לפתוח מפגש חי, להצטרף בקוד או להתנסות בהדגמה. המנחה מאשרת כל מכשיר לפני קבלת מידע חסוי. למכשירי משתתפות יש להשתמש בכתובת רשת/HTTPS של השרת; localhost במכשיר אחר אינו אותו שרת.

```sh
npm run build
npm start
```

המימוש החי משתמש בשרת יחיד וב־SQLite על דיסק קבוע, ללא צורך בחשבונות או מפתחות API. אינו מתאים למערכת קבצים זמנית של Serverless או למספר שרתים בלתי מתואמים. לסנכרון נעשית קריאת מצב מורשית כל שתי שניות. מנוע הדומיין נפרד מהתצוגה וממסד הנתונים, כך שניתן להחליף את מתאם השמירה בעתיד.

## הגדרות

- `DATA_DIR`: תיקיית מסד הנתונים; ברירת מחדל `data/` בתוך הפרויקט. עליה להיות ניתנת לכתיבה ובעלת דיסק מתמיד.
- `APP_ORIGIN`: כתובת HTTPS ציבורית מדויקת, ללא slash סופי, לבדיקת מקור בקשות מאחורי reverse proxy.
- `COOKIE_SECURE`: ברירת מחדל true בהפקה. `false` מותר רק לבדיקת production מקומית על HTTP.
- `PLAYWRIGHT_CHROMIUM_PATH`: נתיב לדפדפן בדיקה מותקן, אם קיים.

אין סודות ב־`.env.example`. אין צורך בהוספת Supabase כדי להריץ את היישום הנוכחי.

## בדיקות

```sh
npm run typecheck
npm test
npm run test:e2e
```

Playwright משתמש ב־Chromium מותקן כאשר הוא זמין; אחרת יש להריץ `npx playwright install chromium`. הבדיקות כוללות מנוע דטרמיניסטי, responsive, axe, הדגמה ללא רשת, חמש משלחות, הרשאות ישירות, מקרן ושחזור טיוטות. קובצי צילום ו־trace נשמרים רק בתוצאות הבדיקה ואינם נכנסים ל־Git.

## גבולות ותוכן

זוהי גרסת התנסות עובדת. המקורות המחקריים והמיפוי המוסדי מסומנים בממשק כטעונים אימות מקצועי. לא מוצגים ציטוטים מפלגתיים לא מאומתים. אין להציג את היישום כמאושר לשימוש בהפקה לפני ביקורת מקצועית, פיילוט של 60 דקות ובדיקות קוראי מסך ומקרן אמיתי.

תוצאות 2029 הן ענפי סיפור בדיוניים, לא תחזית. סימון תנאי ביצוע במשחק אינו הרשאה משפטית. פירוט המערכת והבדיקות הידניות ב־[תיעוד הארכיטקטורה](docs/architecture.md); מפרט המקור ב־[אפיון המוצר](docs/product-spec.md).

## התנסות ציבורית ב־Vercel

לבדיקת UX במכשיר אחד ניתן לפרסם את ההדגמה הסטטית: `npm run build:demo`. קובץ `vercel.json` מגדיר אוטומטית את הבנייה ואת תיקיית הפלט. אין מסד נתונים או API בפריסה זו. ראו [הוראות הפריסה](docs/vercel.md).
