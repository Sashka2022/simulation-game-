# חדר המצב — רפורמה תחת לחץ

אפליקציית סימולציה חינוכית בעברית RTL: מנחה, חמש משלחות ומקרן. ארבעה משברים לאורך מפגש מתוכנן של 60 דקות, הסכם בשלוש דרגות התחייבות, עתיד מדומה, תיקון ורפלקציה.

## משחק חי ב־Vercel

הפריסה הראשית מריצה Next.js עם PostgreSQL משותף. חברו Neon לפרויקט דרך **Vercel → Storage**, ודאו שהמשתנה `DATABASE_URL` משויך לסביבת הפריסה, ובצעו Deploy/Redeploy. הטבלאות נוצרות אוטומטית. אין צורך במפתחות בצד הדפדפן או בחשבונות למשתתפות.

הגדרות הפריסה כבר ב־`vercel.json`: ‏Next.js, ‏`npm ci`, ‏`npm run build`, פלט `.next`, ‏Node 24.x. יש להסיר Overrides ישנים של ההדגמה (`build:demo` / `dist-demo`) אם הוגדרו בלוח הבקרה.

המנחה פותחת מפגש ומציגה QR/קוד; כל זוג מצטרף ממכשיר משלו ומקבל הרשאה לאחר אישור. מסך ההקרנה נפתח בקישור נפרד. הסנכרון מתבצע אוטומטית כל כשתי שניות, עם רענון בחזרה לרשת או ללשונית.

מדריך מלא: **[חיבור Vercel ו־Neon והפעלת מפגש](docs/live-vercel.md)**.

## הרצה מקומית

נדרש Node.js 24 ומעלה.

```sh
npm ci
npm run dev
```

אם מוגדר `DATABASE_URL` (או `POSTGRES_URL`), השרת משתמש ב־PostgreSQL. ללא משתנה כזה, בהרצה מקומית בלבד, יש SQLite בתיקיית `data/`. ב־Vercel אין שמירה מקומית ואין fallback למסד זמני.

```sh
npm run build
npm start
```

המכשירים צריכים לפתוח את אותה כתובת אתר ציבורית, או כתובת רשת מקומית של השרת בפיתוח. localhost בטלפון אינו המחשב שבו פועל השרת.

## הגדרות

- `DATABASE_URL`: חיבור pooled שסיפקה אינטגרציית Neon. נשאר בצד השרת בלבד.
- `POSTGRES_URL`: חלופה לשילוב קיים. `DATABASE_URL` מקבל קדימות.
- `APP_ORIGIN`: כתובת האתר הציבורית המדויקת, ללא slash סופי; אופציונלי כאשר Host המקורי נשמר ב־proxy.
- `DATA_DIR`: תיקיית SQLite לפיתוח מקומי בלבד.
- `COOKIE_SECURE`: ברירת מחדל true בהפקה. `false` לבדיקות מקומיות על HTTP בלבד.
- `PLAYWRIGHT_CHROMIUM_PATH`: נתיב לדפדפן בדיקה מותקן.

אין להוסיף `NEXT_PUBLIC_` למשתני החיבור ואין לשלוח סודות בצ׳אט. `.env.example` מכיל שמות בלבד.

## בדיקות

```sh
npm run typecheck
npm test
npm run test:e2e
```

לבדיקה מול PostgreSQL אמיתי: הגדירו כתובת של מסד בדיקות מבודד במשתנה `DATABASE_URL`, והריצו:

```sh
npm run test:postgres
npm run test:e2e
```

בדיקות המסד מריצות תהליכי שרת עצמאיים כדי לבדוק נעילות, ניסיונות חוזרים, הרשאות והתאוששות. אין להריצן על מסד הפקה. בדיקות הדפדפן מפעילות שרת בדיקות נפרד בפורט 3100 (ניתן לשנות באמצעות `TEST_PORT`).

## מצב הדגמה

באתר המלא ניתן לבחור ״להתנסות במשחק״ ולהחליף נקודת מבט בין מנחה, משלחת ומקרן. ההדגמה נשמרת בדפדפן ואינה מסנכרנת מכשירים.

חבילה סטטית ללא שרת עדיין זמינה עם `npm run build:demo`. לפריסה סטטית בלבד השתמשו בהגדרות `vercel.demo.json`, ולא בהגדרות הפריסה הראשית. ראו [מדריך ההדגמה הסטטית](docs/vercel.md).

## תוכן ונגישות

המקורות המחקריים והמיפוי המוסדי מסומנים כטעונים אימות מקצועי. אין ציטוטים מפלגתיים לא מאומתים ואין נתוני ילדים אמיתיים. תוצאות 2029 הן ענפי סיפור בדיוניים, לא תחזית.

לפני שימוש חינוכי בהפקה נדרשים ביקורת מקצועית, פיילוט של 60 דקות, ובדיקות קוראי מסך ומקרן אמיתי. פרטים: [ארכיטקטורה](docs/architecture.md), [תוצאות אימות](docs/validation.md), [מפרט המקור](docs/product-spec.md).
