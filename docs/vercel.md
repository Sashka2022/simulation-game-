# פרסום ההדגמה ב־Vercel

הפריסה ל־Vercel מכילה הדגמה סטטית של המשחק הקיים. אפשר לעבור בין מנחה, חמש משלחות ומקרן באותו מכשיר. כפתור ״חזרה למנחה״ זמין גם במסך ההקרנה. אין סנכרון בין מכשירים, API או מסד נתונים בפריסה זו. האפליקציה החיה נותרת זמינה להרצה על שרת עם דיסק מתמיד.

## פריסה מחשבון המחובר ל־GitHub

1. ב־Vercel בחרי **Add New → Project**.
2. ייבאי את `Sashka2022/simulation-game-`, ענף `main`.
3. **Root Directory:** השאירי את שורש הריפוזיטורי (ללא תיקייה נוספת).
4. **Framework Preset:** בחרי **Other**, אם לא זוהה מהקובץ.
5. ההגדרות ב־`vercel.json` הן: Install `npm ci`, Build `npm run build:demo`, Output `dist-demo`. אין צורך במשתני סביבה או בסודות.
6. בחרי Node.js 24.x ולחצי **Deploy**.
7. פתחי את כתובת ה־HTTPS שמתקבלת ב־Chrome באנדרואיד. אם Vercel מציג מסך התחברות, בדקי את הגדרות Deployment Protection של הפרויקט ואת מי תרצי לאפשר לה להיכנס.

ה־URL הסופי נוצר בחשבון Vercel; הוא אינו קיים לפני הפריסה. עדכון הקוד ב־GitHub יפעיל בנייה חדשה כאשר חיבור ה־Git של Vercel מופעל.

## שימוש

- לחצי ״מתחילות את המשחק״.
- בתפריט ״נקודת מבט״ בחרי מנחה, משלחת או מסך הקרנה.
- כדי להתקדם בזמן, חזרי למנחה ולחצי ״לשלב הבא״. בהדגמה אפשר לדלג בין שלבים לצורך בדיקה.
- כל ההתקדמות נשמרת בדפדפן המסוים. איפוס מוחק את ריצת ההדגמה המקומית.

## בדיקה מקומית של אותה חבילה

```sh
npm ci
npm run build:demo
node tests/preview-smoke.mjs
```

הבדיקה מפעילה שרת זמני, בודקת את שלושת הממשקים במסך מגע מדומה ואת מדיניות האבטחה של הפריסה, ומכבה את השרת בסיום. אינה מהווה בדיקה על מכשיר אנדרואיד פיזי.
